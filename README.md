## 这个网站

用 Vue 3 + Vuetify + Vite 构建的个人主页，包含个人信息、项目卡片、动态/静态壁纸、音乐播放、隐藏诗歌等模块。推送 `main` 分支后由 GitHub Actions 自动构建并部署到 GitHub Pages。

### 本地运行

```bash
npm install
npm run dev
```

### 构建与部署

```bash
npm run build
```

推送到 `main` 分支后，GitHub Actions 会自动完成构建与部署（工作流见 `.github/workflows/deploy.yml`）。

### 自定义配置

个人信息、标签、壁纸、项目卡片、打字机文案、隐藏诗歌等都在 [`src/config.js`](./src/config.js) 中配置。
